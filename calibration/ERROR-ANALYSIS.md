# Why Marlo's engine is wrong on real pages

Generated by `node scripts/error-analysis.mjs` from `real-marlo-verdicts.json` and the resolved cells in `corpus/real/adjudication/`. Do not edit.

On the 1023 resolved real-page cells, Marlo's own engine reports 9 false positives and 31 false negatives among the rules it evaluates. A further 34 failures fall on rules it cannot evaluate without layout, and count against its recall in the calibration table. Every wrong cell is listed below with what Marlo said, what both raters said, and a root cause. The ground truth is model-adjudicated; see `corpus/real/adjudication/RATER-VALIDITY.md` for how accurate that process is.

## Findings

1. **The static renderer, not rule logic, causes most false positives.** 0 of 9 come from rule logic that contradicts the ACT rule text. 8 come from the static renderer, which does no layout and so cannot see that a stylesheet hides an element. 1 is a cell whose ground truth the pinned rule text does not support, listed rather than fixed toward the raters.
2. **The largest single cause accounts for 16 of the 40 wrong cells.** Cannot tell whether a hidden image is decorative (abstention).
3. **Most false negatives are abstentions.** 31 of 31 are cells where Marlo answered cantTell, mostly because a bypass rule depends on what repeats across pages, or because whether an image is decorative is a judgment. Strict grading counts an abstention on a failure as a miss.
4. **The ACT suite does not catch these.** 3 rules with real-page errors (2ee8b8, b40fd1, c487ae) score perfectly on their ACT test cases, because no test case exercises the construct that fails here.
5. **A browser renderer would change the picture.** Rerun in headless Chromium, Marlo's precision is 0.966 against 0.757, and its recall 0.602 against 0.301. Most of the recall comes from rules that need layout. Chromium removes 8 of the 9 false positives and introduces 2 new errors. This compares Marlo with itself; the comparison between engines in the calibration table uses the static renderer for all four.

"Perfect on ACT" lists the rules among them that Marlo gets entirely right on the ACT test cases. "Chromium corrects" counts the cells the browser renderer gets right.

### Cannot tell whether a hidden image is decorative

Whether an image left out of the accessibility tree carries information is a judgment about its content. Marlo finds the image, an `img`, an unnamed or `aria-hidden` inline `svg` or a `canvas`, and asks for a person to check; the raters found brand logos, close glyphs and a search icon whose meaning was otherwise lost.

### Cannot tell what repeats across pages

Bypass rules turn on whether a block repeats on other pages of the site, which one page cannot show. Marlo answers cantTell; the raters judged the site header repeated and found no skip link, landmark or other way past it. That includes a `main` landmark that opens with the logo link or a header holding the menu, which Marlo used to pass and now asks about.

### Evaluates an element a stylesheet hides

A button, link, field or focusable descendant is hidden by a page stylesheet: a `display:none` class on an empty edit link, a sidebar toggle with a mismatched `aria-label`, a `.hidden` link inside an `aria-hidden` region. The static renderer resolves no styles, so the rule checks something nobody can perceive. These rules read resolved `display` and `visibility` where a renderer supplies them (D-016), so in headless Chromium the element is left out and the error goes away.

### Applies label-in-name where the raters saw abbreviations

The visible labels "EN" and "Paweł Kuna UI Designer" differ from the names "Select language" and "Open user menu". The raters put both links outside the rule because the labels hold abbreviations. The pinned rule does exclude abbreviations, but its own Failed Example 1, a link showing "ACT rules" named "WCAG", treats initialisms in the label and the name as in scope, so nothing in the text separates "EN" or "UI" from them. Marlo keeps the rule as its examples apply it and reports the cell as a suspected ground-truth error rather than changing the rule toward the raters.
