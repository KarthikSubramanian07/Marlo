## What the two views mean

**ACT consistency** is W3C's official verdict, from `pages/implementations/mapping.md`. Under that protocol `cantTell` is an allowed outcome for every example type, so an implementation that never commits grades as `consistent` while telling a developer nothing.

**Strict precision and recall** count `cantTell` as no detection. That is what a user experiences: whether the violation will be found, and whether a clean report means clean.

The **flattered** column marks rules where the two disagree in the direction that matters: officially consistent, and strict recall below 0.5. That is the column nobody publishes, and it is why this table has two halves. See [DECISIONS.md D-004](../DECISIONS.md#d-004).
