# The analysis behind the calibration table, in Chromium

Generated by `pnpm calibrate` from the same harness pass as the table, case by case. Do not edit: `pnpm calibrate --check` regenerates it and fails if any figure moved.

Generated 2026-10-29. Renderer: `browser`. Commit: a dirty tree. Every interval is a Wilson score interval at 95 percent.

## Why this exists

The table's routing is chosen from the same per-rule grades the table publishes, and the router refuses any engine that flagged a passing case. Scoring the routed engine on those same cases is an in-sample figure, optimistic by construction. The figures below score the router on cases it did not see, and measure what `marlo scan` reports as a whole.
